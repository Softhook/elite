This runs the actual cover selection logic used in-game, then simulates a short firefight to verify that cover blocks shots and that fleeing triggers when hull is low. Asteroids are randomized in size and position each run, and ships avoid colliding with them. When behind cover, enemies only fire during peek periods (when peek timer > 0).
Expected: enemy positions behind a rock (green line shows approach path), fires only during peek periods when behind cover (watch peek timer), blocked shots appear gray, then the ship flees to the upper-right once hull < 40%.
