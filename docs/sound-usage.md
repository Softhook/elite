# Sound usage map

Updated: 2025-10-25

This document lists each sound key defined in `soundManager.js` and where it’s used across the codebase. Line numbers are approximate and may shift with edits.

Notes
- “World sounds” are played with `soundManager.playWorldSound(name, x, y, listenerPos)`.
- “UI sounds” are played with `soundManager.playSound(name, volMultiplier?)`.
- `explosionSmall`/`explosionLarge` are selected indirectly by `SoundManager.playExplosion(size, ...)`.
- Backup-only: entries under `*.backup.js` or `starSystem.backup.js` are not part of the active game flow.
- Unused: sounds defined with no current callers.
